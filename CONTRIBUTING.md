## Contributing Guidelines

1. All code contributions must be human-made, not AI generated. Failure to do so will result in a swift rejection of any PRs made.
2. You must be an active member of the UGC/ASP communities to be able to contribute.
3. Please make sure that an issue is reported on GH before starting work on it.
4. Please reach out to one of the maintainers on discord before starting work on an issue to make sure that nothing is already WIP to address the issue.
